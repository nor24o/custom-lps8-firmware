Semtech SX1302 HAL 2.1.0 Features Integrated in raw_lora_app

All Semtech SX1302 HAL capabilities have been integrated into raw_lora_app and LuCI as optional, non-breaking features:

1. Concentrator Thermal Telemetry
Queries on-chip thermal sensor via lgw_get_temperature() during heartbeat loops. Reported on TCP status port 5557 and displayed in live °C badge on LuCI Realtime Status.
2. Hardware 1-µs Clock & PPS Trigger
Reads internal hardware counter via lgw_get_instcnt() and last PPS trigger via lgw_get_trigcnt(). Enables microsecond-accurate timekeeping for Class B downlinks.
3. Realtime Radio Status & ARB Stats
Queries live radio state via lgw_status() (TX_FREE, TX_SCHEDULED, TX_EMITTING, RX_ON) and per-channel preamble detect stats via sx1302_arb_get_debug_stats_detect().
4. Extended RX RF Metadata & Packet Feed
Captures channel noise floor (rssic), SNR dynamic range (snr_min..snr_max), frequency offset (foff Hz), and hex payload preview into /tmp/lora_packets.json for LuCI live stream.
5. Timestamped Downlink & CW Tone Generator
Supports microsecond-scheduled downlinks (TIMESTAMPED / ON_GPS), Continuous Wave RF tone generator (MOD_CW), and instant transmission abort (lgw_abort_tx()).
6. Selective Multi-SF Demodulator Mask
Allows selectively enabling or disabling individual spreading factors (SF5–SF12) via sf_mask bitmask in /etc/lora/config.json or LuCI settings form.
