<%:Home Assistant Device Architecture%>

When a LoRa node transmits or is registered in SQLite, the gateway automatically registers it in Home Assistant over MQTT Discovery.

  • Device Grouping: All metrics for a node (Temperature, Battery, RSSI, Switch) appear under one unified Device Card in Home Assistant.
  • Areas & Groups: The node's group_name is set as the suggested_area (e.g. "Garden", "Indoor").
  • Bidirectional Downlinks: When you toggle a switch in Home Assistant, HA publishes to lora/<NODE>/set. The gateway checks LBT, transmits the LoRa frame, and updates the switch state immediately.
  • Snappy MQTT: Instant sub-second updates without web polling or HTTP overhead.
